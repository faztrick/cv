## 📋 All Available Commands

### Core Features
| Command | Description |
|---------|-------------|
| `npm start` | Show help menu |
| `npm run panel` | Start admin panel (port 3000) |
| `npm run parse-cv` | Parse your resume |
| `npm run generate-emails` | Generate job emails |
| `npm run job-agent` | View job search profile |

| Command | Description |
