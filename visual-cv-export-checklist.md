# Visual CV — Export Checklist

Use this checklist before exporting your Visual CV from Figma.

---

## 1) Layout & content

- [ ] Margins respected (≥ 120 px on A4 2480×3508)
- [ ] No line overflows; bullets ≤ 2 lines
- [ ] Dates aligned right; roles and companies aligned left
- [ ] Contact details correct and clickable (email/links)

## 2) Styles & variables

- [ ] All text layers have text styles (Display, H1, H2, Body, Caption)
- [ ] Color layers use color styles (Primary, Accent, Surface, On-Surface)
- [ ] Spacing conforms to scale (4/8/12/16/24/32)
- [ ] Contrast AA met (dark theme)

## 3) Components & naming

- [ ] Components from `CV/` namespace used for header, sections, and cards
- [ ] Layer names clean; no duplicates for top-level frames
- [ ] Icons centered and 16–20 px

## 4) Exports

- [ ] PDF export for print/share (vector text)
- [ ] PNG @2x for quick preview (optional)
- [ ] File name pattern: `Muhammed-Fasil-PV-CV.pdf`

## 5) Final sanity check

- [ ] No spelling mistakes
- [ ] Dates consistent and correct
- [ ] Key achievements appear in the first 1/3 of the page
