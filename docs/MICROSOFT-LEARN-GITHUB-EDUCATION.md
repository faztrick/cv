# Microsoft Learn → GitHub Education Proof Guide

Microsoft Learn is a great way to show **recent learning activity**, but GitHub Education student benefits are primarily intended for learners who are **currently enrolled in a degree- or diploma-granting program**.

---

## Where Microsoft Learn helps

1. **Free learning platform** from Microsoft
2. **Transcripts/achievements** can be downloaded or printed
3. **Recent activity** is visible in your profile
4. **Achievement records** with dates
5. **Owned by Microsoft** (same as GitHub)

---

## Step-by-Step: Get your Microsoft Learn evidence (supplemental)

### Step 1: Access Your Microsoft Learn Profile

Go to: **<https://learn.microsoft.com/en-us/users/[YOUR-USERNAME]/transcript>**

Or:

1. Visit <https://learn.microsoft.com>
2. Sign in with your Microsoft account
3. Click your profile picture (top right)
4. Click **"Transcript"** or **"Achievements"**

### Step 2: Download Your Transcript

On your transcript page:

1. Look for **"Download transcript"** or **"Print"** button
2. Save as PDF or take a screenshot showing:
   - ✅ Your name
   - ✅ Current date/recent activity
   - ✅ Learning paths or modules in progress
   - ✅ Microsoft Learn logo/branding

### Step 3: What to Show GitHub

Your proof should clearly display:

- **Your full name** (matching your GitHub account)
- **Recent activity** (courses completed or in progress this year)
- **Microsoft Learn branding** (shows it's official)
- **Current date** or recent timestamps

## How to apply (use Microsoft Learn as supplemental)

### Method A: Direct Screenshot Upload

1. Go to: <https://github.com/settings/education/benefits>
2. Click **"Start an application"**
3. When asked for proof, upload your primary enrollment proof (school email or documents), and optionally include your Microsoft Learn screenshot/PDF showing:
   - Your name
   - Recent completions (2024-2025)
   - Microsoft Learn branding

### Method B: Link Your Profile

Some users successfully link their public Microsoft Learn profile URL:

```
https://learn.microsoft.com/en-us/users/[YOUR-USERNAME]/
```

Include this URL in your application notes showing active learning.
