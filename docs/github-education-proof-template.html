GitHub Education — Proof Template (Student / Teacher)

Fill placeholders, then print to PDF. Reviewers need: name, institution, and a current date/term. Online learning profiles can be included as supplemental evidence.
Tip: In your browser, use Print → Save as PDF.

Option C — Supplemental proof (Online learning profile)

If you don’t have a school-issued email, a degree/diploma enrollment document is usually the strongest proof. You can optionally include an online learning transcript/profile as supplemental evidence of recent learning.

  • Platform: [Microsoft Learn / Coursera / edX / etc.]
  • Profile/Transcript URL: [LINK]
  • Recent activity date: [YYYY-MM-DD]
  • What to attach: PDF/screenshot showing your name + recent activity

Quick checklist before you upload

  • Your name is visible and matches your GitHub account name.
  • Institution name is visible.
  • A current date/term is visible (this is the #1 missing piece).
  • Document is readable (no blur, no glare).
