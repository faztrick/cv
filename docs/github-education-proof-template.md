# GitHub Education — Proof Template (Student / Teacher)

This template is designed to help you submit a clear, verifiable document for GitHub Education.

> Tip: GitHub reviewers typically need to see **your name**, **institution**, and a **current date/term**.

---

## Option A — Enrollment Verification Letter (Student)

**[INSTITUTION LETTERHEAD / LOGO]**

**Date:** [YYYY-MM-DD]

**To whom it may concern,**

This letter confirms that **[FULL LEGAL NAME]** (Date of Birth: **[DOB optional]**) is currently enrolled at **[INSTITUTION NAME]**.

- **Student ID:** [STUDENT ID]
- **Program / Degree:** [PROGRAM NAME]
- **Enrollment status:** [Full-time / Part-time]
- **Academic term:** [TERM + YEAR] (e.g., Fall 2025)
- **Expected graduation:** [MONTH YEAR] (optional)

This letter is issued upon the student's request for verification purposes, including **GitHub Education** benefits.

Sincerely,

**[SIGNATURE]**

**[FULL NAME OF AUTHORIZED PERSON]**
[Title / Role]
[Department / Office]
[Institution Name]
[Institution Address]
[Institution Phone]
[Institution Email]

## Option C — Supplemental proof (Online learning profile)

If you do not have a school-issued email, a **degree/diploma enrollment document** is usually the strongest proof.

You can optionally include an online learning transcript/profile as *supplemental* evidence of recent learning activity.

- **Platform:** [Microsoft Learn / Coursera / edX / etc.]
- **Profile/Transcript URL:** [LINK]
- **Recent activity date:** [YYYY-MM-DD]
- **What to attach:** A PDF/screenshot that shows your **name** and **recent activity**.

---

## If you don’t have a letterhead

If your school can’t provide letterhead, it still helps if the letter includes:

- Official contact email/phone for verification
- A stamp/seal (if available)
- A signature + printed name/title

---

## Attachments that work well (if you can get them)

GitHub also accepts these as proof (examples from GitHub Docs):

- School ID **with current enrollment date**
- Class schedule
- Transcript
- Enrollment/affiliation verification letter

---

## Privacy note

Only share what you must. If your document includes extra sensitive info (e.g., full address), you can often redact it—**but do not redact your name, institution, and current term/date**.
