# Apply to GitHub Education (Quick Guide)

This is a quick, practical guide for applying to GitHub Education.

## Where to apply

- Education benefits settings: <https://github.com/settings/education/benefits>
- After approval, education portal: <https://github.com/education>

## Student (Student Developer Pack)

You qualify if you are enrolled in a degree- or diploma-granting program, have a GitHub personal account, and can verify student status (via school email or documents).

**Accepted proof examples (GitHub Docs):**

- School ID with current enrollment date
- Class schedule
- Transcript
- Enrollment/affiliation verification letter

**Best practice:** your proof should clearly show **your name**, **institution**, and a **current date/term**.

> Note: Self-paced learning platforms (for example, Microsoft Learn) can be helpful as **supplemental evidence of recent learning**, but GitHub Education is primarily intended for learners **currently enrolled** in an accredited degree/diploma program.

Template you can use:

- `docs/github-education-proof-template.md`
- `docs/github-education-proof-template.html` (print to PDF)

## Teacher

You must be an educator/faculty/researcher, have a verifiable school email, and upload documentation proving affiliation.

## Common issues

- No current date/term shown → use a class schedule or official letter with date.
- Name mismatch → align GitHub profile name or use documentation showing the same name.
- Blurry photo → re-take with good lighting.

## Official docs

- Student apply: <https://docs.github.com/en/education/about-github-education/github-education-for-students/apply-to-github-education-as-a-student>
- Teacher apply: <https://docs.github.com/en/education/about-github-education/github-education-for-teachers/apply-to-github-education-as-a-teacher>

## If you’re not currently enrolled

If you’re not currently enrolled in a degree/diploma program, GitHub Education may not be approved. Two practical alternatives:

- **GitHub Copilot Pro for open source maintainers** (if eligible): <https://github.com/settings/copilot>
- **GitHub Pro** subscription: <https://github.com/pricing>
